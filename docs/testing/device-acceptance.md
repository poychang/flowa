# 跨裝置協作驗收

基準：2026-09-27，main `12d3355`，PR #3 已合併。本階段增加自動化覆蓋並準備實機驗收；不把模擬裝置視為 iPad 實測。

## 自動化

```sh
pnpm exec playwright install chromium webkit
pnpm test:devices
```

測試使用真實本機 relay 與不同瀏覽器引擎，三項案例：

1. Chromium 管理者與 WebKit 編輯者互相繪圖，WebKit 觸控平板設定的唯讀訪客接收相同內容；以觸控點擊匯出 JSON，驗證物件 ID、幾何、樣式與版本，編輯者重新載入後仍一致。
2. WebKit 斷線後與 Chromium 分別編輯，確認兩端各自儲存不同內容，再連線收斂；下載的恢復副本必須等於重連前離線內容。
3. Chromium 平板設定以瀏覽器觸控事件繪圖（非滑鼠或 DOM 合成事件），切換直向／橫向尺寸、重新載入並匯出 JSON，確認圖形內容與操作按鈕仍可用。

畫面尺寸為 820×1180 與 1180×820；測試切換 viewport，不代表真實感應器旋轉。WebKit 平板設定使用 touch tap 操作控制項，沒有模擬 Apple Pencil。`test-results/devices/` 會保存畫面與失敗追蹤。一般跨瀏覽器回歸仍見 [cross-browser.md](cross-browser.md)。

Chromium 繪圖使用 CDP `Input.synthesizeScrollGesture` 的 touch 模式，在畫布上產生完整觸控拖曳，再以 Playwright `tap()` 操作匯出。手動快速送出 `dispatchTouchEvent` 的診斷版本曾在拖曳後收不到 click，因此不把那種輸入序列當作實機問題結論；仍須依下方清單檢查真實裝置。JSON 比較僅容許 Excalidraw 還原時將元素空綁定 null 改為 []，其餘元素欄位均比對。

## 實機前置條件

2026-09-28 Windows 本機：上述三項通過，另重複觸控案例三次通過；已檢視橫向唯讀平板與觸控橫直向截圖。這些結果不等同實際 Safari/iPad 驗收。

準備一台 iPad／Safari、桌面瀏覽器及可用的觸控筆。記錄 OS、瀏覽器版本與筆型號。以裝置可連線且憑證受信任的 HTTPS 前端與 WSS relay 測試；localhost 指的是各裝置本身，不能把桌面的 loopback 連結交給 iPad。relay 的 Origin allowlist 必須與前端來源一致，保持全服務最多 4 條連線。

先用非敏感測試畫布，包含繁體中文、自由筆、填色圖形、綁定文字及連接箭頭。等待「已存於此裝置」，另存 JSON 作為基準；正式 PWA 另須等待「離線可用」。目前尚未部署可供實機使用的 HTTPS 環境。

## 實機清單（均待驗證）

| 項目 | 操作 | 通過條件 |
| --- | --- | --- |
| 原生安裝 | Safari 分享選單加入主畫面，再由圖示啟動 | 獨立視窗可開啟；安裝不遺失草稿 |
| 離線啟動 | 快取完成後關閉網路、重開應用程式 | 單人草稿可讀、編輯、儲存與匯出；首次無快取不得宣稱離線可用 |
| 中文與匯出 | 離線加入中文字及圖形，輸出 PNG/SVG/JSON | 字形、顏色可讀；JSON 在乾淨瀏覽器可還原 |
| 筆與手勢 | 畫自由筆、手指平移／縮放、手掌接觸 | 不誤畫、不卡在拖曳中；記錄實際筆支援，不承諾所有壓感 |
| 軟鍵盤與旋轉 | 編輯文字、開合鍵盤並旋轉裝置 | 內容不遺失；編輯區、儲存狀態與匯出仍可操作 |
| 鎖屏恢復 | 已儲存後鎖屏、切換應用程式，再返回 | 草稿保留；協作重新驗證並恢復，或明確提示失效 |
| 跨裝置斷線 | iPad 斷網時雙方分別編輯，再連線 | 不以空白或舊快照覆蓋；恢復副本可匯出 |
| 更新保護 | 有未保存變更時取得新版，開第二視窗再嘗試更新 | 不自行重載；多視窗阻擋，關閉後備份成功才更新 |
| 儲存與清除 | 檢查持續保存提示，先匯出後清除網站資料 | 不把持續保存宣稱為雲端備份；可從 JSON 恢復 |

每項記錄：日期、提交 SHA、裝置／OS／瀏覽器、步驟、預期與實際結果、截圖或非敏感 JSON、缺陷編號。未執行寫「未測」，失敗不得只以模擬器結果替代。此清單不包括 30 分鐘 WAN 長測或 Azure 免費配額驗收。
